# 地下城勇士 Q版 — 一页策划书（GDD）

- 题材：Q版地下城横版动作：勇士挥剑连斩、释放鬼影斩，抵御一波波小怪与哥布林，拾取金币与经验升级，通关结算
- 类型：beat_em_up　视角：side　画布：640x360　风格：hibit
- 操作：touch_joystick_actions　屏幕方向：landscape

## 核心循环（一句话）
走位 → 连招/技能清怪 → 掉落金币与经验 → 升级变强 → 下一波更密的敌潮 → 通关结算

## 目标与失败条件
- 胜利：清光 5 波敌人（第 5 波含 4 哥布林 + 2 壮汉）后进入结算页，显示通关成功与 S/A/B/C 评级。
- 失败：生命值归零（HP 初始 12，被哥布林打 4、壮汉打 9），进入失败结算页，评级固定 C，按 R 重开。

## 核心玩法要素（三到五个）
1. 三段普攻连招（伤害 4/4/6，1.2 秒内续接，第 3 段为「combo3」并触发连击计数与音效）。
2. 两档技能：蓄力斩（伤害 14 / 范围 40 / CD 1.2s）与鬼影斩（伤害 26 / 范围 62 / CD 3.0s，范围大可多目标）。
3. 敌人 AI：哥布林（HP26 / 速 56 / 攻距 26 / 伤 4 / 间隔 0.9s）与壮汉（HP70 / 速 38 / 攻距 36 / 伤 9 / 间隔 1.5s），追击玩家、进攻击退、彼此轻微互斥。
4. 掉落与成长：击杀掉落金币（黄菱形）与经验（蓝珠），靠近自动拾取；经验满自动升级，升级加最大生命 4、伤害 +15%。
5. 波次推进与结算：5 波逐波登场，波间 1.6 秒喘息，通关/失败进入统一结算页。
